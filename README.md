# Mimic

Mimic is the sequence-embedding architecture package in the Poseigen family.
It provides unified single- and dual-input models built from Trident's neural
network components.

Part of the [Poseigen ecosystem](https://github.com/Husam94/poseigen).

## Installation

```bash
pip install poseigen_mimic
```

For local development, install from source using your preferred editable-install
workflow.

## Usage

```python
from poseigen_mimic import Mimic, Dual_Mimic
```

## Related Projects

- `poseigen_trident`: neural-network building blocks used by Mimic.
